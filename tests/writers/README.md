# Test writers

Every writer, company, school, number and contact detail in this folder is made up for testing. Any match with a real person or company is chance. The files hold no notes about the tests, because each file goes into a review packet as the writer would send it. What each test expects lives in `tests/keys/`.

| Folder | Writer | Pieces |
|---|---|---|
| `a-quintero` | An emergency nurse manager applying to run three primary care clinics | Posting, resume, a clean letter and the same letter with eight planted flaws |
| `b-okafor` | A grocery planning analyst applying for a freight forecasting job | Posting, resume, letter, a strategy file that must never reach a reviewer, and a career record used as a decoy |
| `c-abernathy` | A chemistry teacher moving into instructional design | A letter with no posting |
| `d-ferreira` | A restaurant manager writing to a hotel's hiring lead | An outreach note that runs over a 300-character limit |
| `e-castillo` | A warehouse shift supervisor applying to run a shift at a new distribution center | Posting, resume and pages saved from the firm's website. Her only record is the resume |
| `f-haddad` | A middle school math department chair applying to coordinate a district's math curriculum | Posting, resume, a longer master resume and a cover letter she wrote in 2021 for another job |
| `g-whitfield` | A civil engineer at a water utility applying for a capital programs job | Posting, resume and the text of his LinkedIn profile |
| `h-marsh` | An operating room charge nurse applying to be a clinical nurse educator | Resume only. The posting she applies to is a real one, so its text stays out of this repository, and its link is in `tests/keys/h-marsh.md` |

Writers E to H are for candidate-positioning. Their postings and firm pages name made-up firms on the reserved `.example` web domain, apart from writer H's real posting.
