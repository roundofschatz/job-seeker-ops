# Test writers

Every writer, company, school, number and contact detail in this folder is made up for testing. Any match with a real person or company is chance. The files hold no notes about the tests, because each file goes into a review packet as the writer would send it. What each test expects lives in `tests/keys/`.

| Folder | Writer | Pieces |
|---|---|---|
| `a-quintero` | An emergency nurse manager applying to run three primary care clinics | Posting, resume, a clean letter and the same letter with eight planted flaws |
| `b-okafor` | A grocery planning analyst applying for a freight forecasting job | Posting, resume, letter, a strategy file that must never reach a reviewer, and a career record used as a decoy |
| `c-abernathy` | A chemistry teacher moving into instructional design | A letter with no posting |
| `d-ferreira` | A restaurant manager writing to a hotel's hiring lead | An outreach note that runs over a 300-character limit |
