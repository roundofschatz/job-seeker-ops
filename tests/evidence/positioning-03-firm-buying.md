# Positioning test 3: what the firm is buying

Spec: "For a posting whose duties list points one way and whose problem points another, the case follows the problem."

- Run e1, writer E, with the same session and setup as test 2. Files: `positioning-runs/e1/`.
- The posting's duties list asks for routine supervision: cycle counts and inventory accuracy, schedules, start-up meetings, safety audits and weekly reports. Its opening paragraph names the problem: a new building where "we ship 82% of store orders on time against a goal of 97%".

## What the file says

Line 1 of the case: "Ironwood Trail wants a supervisor who has brought a new building up to speed before, to lift Sparks from 82% of store orders on time to its goal of 97% so its stores stop running short of gear."

P1, the top proof, is "Opening the Fernley cross-dock", where on-time shipping "rose from 79% to 98% in five months". Inventory accuracy, the duty the list puts first, comes fourth, as P4.

## Without the skill

The run with no skill also led with the Fernley opening. This test passes either way, so it shows the skill keeps the problem in front, rather than showing what the skill adds.
